## 一文で
**ChatGPTやGeminiが、自社の化粧品を薦めているかを美容に特化した質問で定点観測し、競合との差と、薬機法に配慮した改善案を出す、化粧品ブランド向けのWebサービス。**

## 買い手
- 主：中小・D2C化粧品ブランドのマーケティング担当、代表者（年商数千万〜数十億円規模を想定）
- 副：化粧品ブランドを支援するWeb制作・広告代理店（複数ブランドを管理）

## 解決する課題
- 消費者が「敏感肌 化粧水 おすすめ」とAIに聞く時代に、**自社が薦められているか、なぜ競合が薦められるのかが分からない**
- 汎用のLLMOツールは、美容の質問を自分で考える必要があり、改善案が薬機法に合わない

## 中心となる体験（MVP）
1. **無料の簡易診断**（登録不要）：ブランド名とカテゴリー（例：化粧水）を入れる → 美容特有の質問10問を主要AIに聞き、自社が薦められた割合と、代わりに薦められたブランドを表示
2. **アカウント登録・ブランド設定**：自社ブランド、主力商品、競合ブランド（3〜5社）、狙う肌悩み・年代・価格帯
3. **質問セットの自動生成**：美容の質問ライブラリ（肌悩み×年代×価格帯×用途）から、そのブランドに合う質問を作る。利用者が編集できる
4. **定点観測**（週1回）：質問ごとに複数のAIに複数回聞き、言及の有無、順位、薦められた理由、引用元のURLを記録
5. **レポート**：推薦率、競合との比較、推移、AIが引用しているサイト（自社サイト・@cosme・メディアなど）
6. **改善案**：「どの情報が足りないか」を根拠つきで提示。改善の文案は**薬機法のルールに照らして確認してから**表示（化粧品の効能の範囲を超える表現は出さない）

## AIの役割と、コードの役割
| 処理 | 担当 |
|---|---|
| AIに質問して回答を得る | 各社の公式API（Web検索つき） |
| 回答からブランド名・順位・理由・引用元を抜き出す | LLM（構造化出力）＋辞書照合（コード） |
| 推薦率・順位・推移・競合比較の計算 | コード（決定論的） |
| 改善案の文章 | LLM（集計データの範囲内に限定） |
| 薬機法の表現確認 | ルール（コード）＋LLMによる補助。最終判断は利用者 |

## 想定技術構成（Phase 4で比較・確定）
- Next.js + TypeScript + Tailwind CSS / Vercel（Cron機能で定点観測）
- Supabase（認証・PostgreSQL）
- AIのAPI：OpenAI（Web検索つき）、Gemini（Google検索グラウンディング）。Claude・Perplexityは費用を見て追加を検討
- 決済：Stripe（MVPでは請求書払いでの手動対応も可）
