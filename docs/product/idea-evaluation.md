## 1. 足切り条件（すべて満たさない案は検討しない）

## 4. 推薦：⑨ 美容ブランド向け AI推薦モニター

### 推薦理由
1. **すでにお金が動いている**：国内のLLMOツールは月額7,980〜49,800円で20種類以上販売されており、単発の診断も5万円で売られている。新しく予算を作ってもらう必要がない。
2. **美容はAI経由で商品を探される代表的な分野**：生成AIから小売サイトへの流入は2025年に304%増え、美容・パーソナルケアはAI経由の商品発見で最も目立つ分野とされている（Euromonitor）。海外ではeMarketerや5W PRが美容ブランドのAI露出を指数化している。
3. **国内には美容に特化した道具がない**：汎用ツールは「どのAIで、何回言及されたか」は測れるが、「乾燥肌×30代×3,000円台の化粧水」のような美容特有の質問の設計や、同じ価格帯の競合との比較は利用者まかせ。
4. **改善案を薬機法に照らして出せることが決定的な差**：汎用ツールの改善案（「効果をはっきり書く」など）をそのまま化粧品に使うと、薬機法違反になりうる。改善案を「化粧品で表現できる効能の範囲」に照らして確認してから出す。この確認機能は案⑩そのものなので、**後から単体商品としても売れる**（収益源が2本になる）。
5. **無料の簡易診断で集客できる**：ブランド名を入れるだけで「主要なAIがあなたのブランドを薦めるか」を無料で表示し、詳しいレポートと定点観測を有料にする。個人開発者でも営業せずに見込み客を集めやすい。

### 残る不確実性（正直に）
| リスク | 内容 | 対策 |
|---|---|---|
| 回答のずれ | APIで得たAIの回答は、利用者がChatGPTアプリで見る回答（履歴・記憶・地域で変わる）と一致しない可能性 | 「API経由・日本語・同条件で繰り返し測った傾向」と明記。同じ質問を複数回聞き、割合で示す（コードで集計） |
| 競合の追随 | 汎用LLMOツールが美容向けテンプレートを追加する可能性 | 美容の質問ライブラリと薬機法のルールを早く作り込み、事例を発信する |
| 支払意思 | 月額19,800円が受け入れられるかは未検証 | 公開1週目に無料診断と事前登録を出し、登録数と問い合わせで確かめる |
| 営業 | B2Bは問い合わせ対応が必要 | 申し込みから決済まで自動化（MVPでは決済は後回しも可） |
| 法務 | AIの回答に表示された他社ブランド名を、レポートに載せることの扱い | 事実の集計にとどめ、評価・誹謗はしない。専門家確認事項とする |

### 除外した初版1位について
初版で推薦した「肌トラブル成分トレーサー」は課題は本物だが、消費者向けの成分アプリは無料が主流で、月額480円の課金が成り立つ根拠が見つからないため除外した。
